# Automated Daily Instagram Marketing Bot

An automated social media marketing pipeline powered by **Google Gemini**, **Pollinations.ai**, and the **Meta / Instagram Graph API**.

Every day at 04:00 UTC, a GitHub Action runs this bot to generate fresh, engaging captions and promotional graphics for your web products, then publishes them directly to your Instagram Business/Creator profile.

---

## 🛠️ How It Works

1. **Content Generation (`Gemini API`)**:
   - Rotates daily marketing angles (*Problem & Solution*, *Feature Spotlight*, *Workflow Hack*, *Speed & Simplicity*).
   - Produces structured output (Hook, Value Body, CTA, Link, and Hashtags) using Pydantic models.
   - Includes automatic retries and model fallbacks (`gemini-2.5-flash` ➔ `gemini-2.0-flash` ➔ `gemini-1.5-flash`).

2. **Visual Generation (`Pollinations.ai`)**:
   - Uses the prompt generated by Gemini with randomized seeds to produce a fresh 1080×1080 promotional graphic.
   - Pre-caches the image on Pollinations' CDN before Instagram's crawler requests it to avoid crawler timeouts.

3. **Instagram Auto-Publishing (`Meta Graph API v18.0`)**:
   - Creates an Instagram media container.
   - Polls container status until `FINISHED`.
   - Publishes the container directly to your Instagram feed.

## 🔑 Required Secrets & Setup

Configure these secrets in **GitHub Repository Settings > Secrets and variables > Actions**:

| Secret Name | Description | How to Get |
|---|---|---|
| `GEMINI_API_KEY` | Google Gemini API Key | [Google AI Studio](https://aistudio.google.com/) |
| `IG_ACCESS_TOKEN` | Meta Graph API Access Token | Meta Business Suite / Graph API Explorer |
| `IG_USER_ID` | Instagram Business Account ID | Meta Graph API (`/{page-id}?fields=instagram_business_account`) |

### How to get a Long-Lived / Permanent Instagram Access Token:
1. Ensure your Instagram account is a **Professional / Business Account** and linked to a **Facebook Page**.
2. Go to the [Meta Graph API Explorer](https://developers.facebook.com/tools/explorer/).
3. Select your Meta App, choose your Facebook Page, and add permissions:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
4. Exchange the short-lived token for a **60-day Long-Lived Token**, or create a **System User Token** in [Meta Business Suite](https://business.facebook.com/settings/system-users) for a permanent, non-expiring token.

## 💻 Local Testing & Usage

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run a Dry Run (Tests Gemini & Pollinations without posting)
```bash
python main.py --dry-run
```

### 3. Test for a specific website
```bash
python main.py --dry-run --site Wakit
```

### 4. Validate credentials
```bash
python main.py --validate
```
